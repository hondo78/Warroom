Kali über Tor

Ein Kali-Container, der ausschließlich über Tor ins Internet geht, wird von den Agenten per MCP angesprochen. Keine Shell: nur erlaubte Recon-Tools gegen die Ziel-Allowlist, gefährliche/Massen-Muster werden geblockt, jede Ausführung wird protokolliert und kann eine Freigabe erfordern.

Ziel-Allowlist

Nur diese Ziele (CIDRs / IPs / Domain-Suffixe) dürfen gescannt werden — leer = nichts. Bearbeitung im Admin.

Konsole

Ein Befehl pro Zeile, keine Shell: genau ein Programm aus der Liste unten, keine Pipes, keine Verkettung, und jedes Ziel muss in der Allowlist stehen. Was du hier abschickst, läuft sofort — dein Absenden ist die Freigabe. Die Freigabepflicht oben gilt für die Agenten, die über MCP Befehle einreichen.

tor$
