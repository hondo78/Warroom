🔀 KI-Agent — Workflow

Entscheidungs-Pipeline

Jede Stufe durchläuft dieselbe Pipeline. Das LLM wird über strukturierte Ausgaben (Pydantic-Schema via response_format) angesprochen; die Antwort wird typisiert validiert und auf die erlaubten Aktionen der Stufe beschränkt.

⚙️ Global (LLM-Anbindung)

Führt nur nicht-destruktive Aktionen (acknowledge) automatisch aus. Block-Aktionen bleiben immer bis zur Freigabe pending.

🧠 Self-learning auto-approval

Records every human approval/rejection per decision signature (source · action · rule). Once a signature's net score (approvals − rejections) reaches the threshold, matching new decisions are auto-approved and executed — block actions included. The whitelist is always re-checked, so your own IPs stay safe.

Learned patterns

Eligible patterns (net ≥ threshold) auto-approve while learning is active.
