Sophos Central API

OAuth2-Credentials aus dem Sophos Central API Token Management. Tenant-ID wird nach Login automatisch erkannt, falls leer.

Microsoft 365 Audit-Log

Entra-ID-App-Registrierung mit Admin-Consent. Der Collector holt Login-Ereignisse (UserLoggedIn / UserLoginFailed); Fehlversuche landen zusätzlich als Alerts auf der Attack-Map. Anzeige unter Microsoft 365.
Benötigte Application-Berechtigungen:
• ActivityFeed.Read (Office 365 Management APIs) — Login-Audit-Log.
• User.RevokeSessions.All (Microsoft Graph) — für die Login-Überwachung: Session-Widerruf bei Anmeldung von neuem Gerät/Standort.

Entra ID — Login-Blocking (Conditional Access)

Schiebt geblockte IPs in eine Entra Named Location, die an eine Conditional-Access-Policy gebunden ist — M365-Logins von diesen IPs werden dann direkt bei Microsoft abgewiesen. Nutzt dieselbe App-Registrierung wie der M365-Collector, benötigt aber zusätzlich die Graph-Berechtigungen Policy.ReadWrite.ConditionalAccess + Policy.Read.All (Application, Admin-Consent).
Sicherheit: Die Policy wird im Report-Only-Modus angelegt — Erzwingung musst du bewusst im Entra-Portal aktivieren.

Pflicht für die automatische Policy-Anlage — UPN(s) oder Objekt-ID(s), kommagetrennt. Diese Konten werden nie geblockt (Schutz gegen Selbst-Aussperrung).

IOC-Auslieferung an die Firewall

Zwei voneinander unabhängige Wege, die Blocklisten an die Firewall zu bringen — beide können gleichzeitig aktiv sein. Pflege der Listen siehe Blocklist-Seite.

Die Firewall holt die Blocklisten als TXT-Feeds (ein Eintrag pro Zeile) selbst ab — als Third-Party-Threat-Feed konfiguriert, mit X-API-Key-Header. Aus ⇒ die Feeds liefern einen leeren Body (eine pollende Firewall leert damit ihre Liste).
IP-Feed: /ioc_IP
Domain-Feed: /ioc_domain
URL-Feed: /ioc_url
Warroom pusht die Blocklisten aktiv über die Sophos-Central-Firewall-API in den MDR-Threat-Feed der Firewall (POST /firewall/v1/firewalls/{id}/mdr-threat-feed/indicators). Nutzt die oben konfigurierten Sophos-Central-Zugangsdaten.
Leer lassen, um an alle von Sophos Central gemeldeten Firewalls zu pushen.
