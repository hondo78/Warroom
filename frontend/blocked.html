Grundlage der Regel „Ungültige Benutzer (Sofort-Block)": Eine öffentliche IP wird automatisch gesperrt, sobald sie mehrere nicht existierende Benutzernamen durchprobiert. Als existierend gilt jeder Name, der sich hier schon einmal erfolgreich angemeldet hat (Herkunft „gelernt“). Fehlt ein Konto — etwa ein neuer Kollege, der sich noch nie angemeldet hat — trage es hier als gültig nach, sonst gilt sein Name als erfunden. Umgekehrt kannst du Sammel-Konten als ausgeschlossen markieren, damit sie einen Angreifer nicht decken.

Regel testen, ohne zu sperren

Die Regel greift nur während eines Angriffs — an einem ruhigen Tag ist einer funktionierenden Regel nicht anzusehen, dass sie funktioniert. Hier läuft dieselbe Auswertung über die zwischengespeicherten Anmeldeversuche der letzten Stunden, ohne irgendetwas zu sperren: Du siehst, was getroffen worden wäre, und kannst die Schwellen an echtem Verkehr justieren.

Jede Sperre mit ihrer Begründung — welche nicht existierenden Benutzernamen probiert wurden und wie oft.

Zeitpunkt IP Begründung

Jeder Benutzername, den eine überführte Angreifer-IP durchprobiert hat, landet hier. Jede öffentliche IP, die einen dieser Namen probiert, wird beim ersten Versuch gesperrt — ohne Schwelle, ohne LLM. Eine einmal gegen uns eingesetzte Namensliste soll dem nächsten Angreifer keine Schonfrist mehr verschaffen. Namen kommen nur über eine IP hierher, die schon die Schwellenregel gerissen hat; ein Vertipper eines echten Benutzers landet damit nie auf der Liste.

Agent blocks made on OSINT evidence are re-checked against the same providers once a week. When no provider flags the IP any more (e.g. the vulnerability was patched, the host was cleaned up), the block is lifted and the IP lands here. This list blocks nothing — it records that there was a problem and what it was.
