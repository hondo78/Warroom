IOC Block-IP Feed

Die Blocklist wird als TXT-Feed (eine IP pro Zeile) unter folgender URL bereitgestellt. Die Firewall muss den X-API-Key Header mitsenden. Wird bei jedem Block/Unblock automatisch aktualisiert.

Feed-URL: /ioc_IP
Format: text/plain — eine IPv4/IPv6 pro Zeile, sortiert
